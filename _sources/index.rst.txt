**************************************
Liger IRIS DRP Resources Documentation
**************************************

This package (liger_iris_drp_resources) provides resources for the Liger IRIS Data Reduction System:

1. `liger_iris_pipeline <https://github.com/oirlab/liger_iris_pipeline>`_: The main data reduction pipeline for Liger and IRIS.
2. `liger_iris_sim <https://github.com/oirlab/liger_iris_sim>`_: The data simulator for Liger and IRIS.
3. `iris_rawframe_simulator <https://github.com/oirlab/iris_rawframe_simulator>`_: A tool for simulating raw IFS frames for Liger and IRIS (under development).


**Google Drive**

A few resources are directly provided with this package, but most are downloaded from the Google Drive folder linked below.

Users do not need to download these resources manually.

`Link to Google Drive folder <https://drive.google.com/drive/folders/15vSPi9QRine2F2zhZ7xeSXJF7fMXZdoe?usp=drive_link>`_
